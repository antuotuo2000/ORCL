Oracle（甲骨文）

NYSE · ORCL · 美国企业软件及云计算

投资周期：3–5年 · 价值投资视角

先说我的核心判断：Oracle 是一家拥有优秀数据库护城河、正在快速转型为 AI 云基础设施公司的企业，但它现在最大的投资问题不是业务能不能增长，而是巨额资本开支能否转化为自由现金流，以及负债是否会侵蚀股东回报。

我认为 ORCL 值得深入研究，但不能简单地把它当成一家传统的高利润软件公司来估值。

一、公司究竟靠什么赚钱？

Oracle 的业务可以分成四大部分：

1. 云基础设施 OCI（IaaS）

向企业和 AI 公司出租 GPU、服务器、存储、网络和数据中心算力。

(当前主要增长引擎)

2. 数据库业务

企业购买 Oracle 数据库、云数据库服务及相关技术支持。

(核心护城河)

3. 企业应用软件 SaaS

ERP、财务、人力资源、供应链、客户管理等企业软件。

(稳定现金流来源)

4. 硬件及服务

企业服务器、存储设备、技术支持和咨询服务。

最重要的变化是：Oracle 正从一家传统数据库软件公司，转变为一家数据库、企业应用与 AI 云计算基础设施并存的公司。

这意味着它未来的增长空间可能更大，但商业模式也变得更重资产。

我特别关注三个数据。

第一，云基础设施增长121%。

这是非常强劲的增长，说明 Oracle 已经在 AI 基础设施市场获得了真实订单，而不只是讲 AI 故事。

第二，SaaS 只增长10%。

传统企业软件的增长明显低于 OCI。这意味着未来 Oracle 的整体增长越来越依赖数据中心投资，而不是单纯依靠软件订阅。

第三，现金流出现了压力。

这里需要特别说明：官方财报披露的经营现金流是 230亿美元，自由现金流为负50亿美元。经营现金流很强，但大规模资本开支吞噬了现金。

FY2026 全年经营现金流为320亿美元，自由现金流为负237亿美元。

这就是 Oracle 当前最值得警惕的地方：

利润增长不等于股东真正拿到的现金增长。

三、护城河：Oracle 能不能长期赚钱？

我认为 Oracle 有三道比较重要的护城河。

护城河强度原因
数据库生态很强企业核心数据系统迁移成本高
企业软件客户关系强ERP、财务、人力资源等系统深度嵌入企业
云基础设施中等偏强AI算力需求、数据库与云服务协同，但竞争激烈

1. 数据库：Oracle 最值得珍惜的资产

很多大型企业的财务、银行、保险、供应链系统都运行在 Oracle 数据库上。

为什么企业不轻易更换？

  • 数据迁移成本高。
  • 系统中断可能造成巨大损失。
  • 企业已有大量 Oracle 技术人员和软件生态。
  • 更换数据库需要重新测试业务系统。
  • 企业对稳定性和安全性要求很高。

这类护城河与普通消费互联网公司不同。

Oracle 不需要每天吸引消费者，它只需要让企业持续使用它的核心系统。

2. 企业软件：客户黏性很强

Oracle 的 Fusion ERP、NetSuite、HCM、SCM 等产品，属于企业日常经营的基础设施。

企业一旦把财务、采购、人力资源系统部署在 Oracle 上，通常不会轻易更换。

我认为这是 Oracle 长期稳定收入的重要来源。

3. OCI：未来最大的机会，也是最大风险

Oracle 正在争夺 AI 云计算市场。

主要竞争对手：

公司股票代码竞争优势
AmazonAMZNAWS规模、生态和客户基础
MicrosoftMSFTAzure、企业客户、AI生态
AlphabetGOOGLGoogle Cloud、TPU、AI技术

OracleORCL数据库、企业客户、AI算力服务

Oracle 的优势是数据库和云基础设施可以协同销售。

但它并没有形成不可替代的云计算垄断。

尤其是 AWS、Azure 和 Google Cloud 都有雄厚的资金与技术实力。

我的判断：

  • 数据库护城河：9/10
  • 企业应用护城河：8/10
  • 云基础设施竞争力：7/10
  • 整体护城河：8/10

以上是主观投资评分，不是市场统计数据。

四、管理层：值得信任吗？

Oracle 的创始人及长期核心领导者是 Larry Ellison。

我对他的评价是：

商业嗅觉非常强，但资本配置风格比较激进。

优点：

  • 很早就建立了数据库业务的竞争优势。
  • 能够通过收购扩展产品线。
  • 推动 Oracle 从传统软件向云计算转型。
  • 对 AI 基础设施投资非常积极。

需要警惕：

  • 大规模资本开支带来融资需求。
  • 负债规模增加。
  • 股权融资可能摊薄现有股东。
  • AI 数据中心的投资回报还需要时间验证。

另外，Oracle 已进入双 CEO 管理阶段，不能只看创始人个人能力，也要观察新管理团队能否持续执行战略。

五、最重要的问题：Oracle 的债务和自由现金流

这是我认为价值投资者最需要认真研究的部分。

根据 FY2027 Q1 资产负债表及市场财务统计：

指标数据
现金及现金等价物约364亿美元
总债务约1690亿美元
净债务（粗略）约1330亿美元
FY2026 自由现金流\-237亿美元
Q1 FY2027 自由现金流\-50亿美元

这意味着 Oracle 已经不是传统意义上轻资产、高自由现金流的软件企业。

它正在变成一家需要大量投资建设数据中心的基础设施公司。

但有一个值得关注的积极变化

2026年10月28日，Oracle 投资者日公布了新的长期计划：

同时，Oracle 承诺 FY2027–FY2030 投资周期内，新增资本市场融资限制在200亿美元，预计包括100亿美元股权和100亿美元新增债务；不包括现有债务再融资。

这里有一个非常重要的投资判断：

如果 Oracle 能够实现 FY2029 年300亿美元以上的自由现金流，那么现在的巨额资本开支可能是在为未来创造巨大价值。

但这仍然是管理层预测，不是已经实现的业绩。

风险严重程度我的判断
巨额资本开支高可能长期压制自由现金流
债务增加高利息支出影响净利润
AI客户集中高大客户取消或延迟合同会产生影响
AWS、Azure竞争高云计算价格和利润率可能承压

数据库竞争中迁移成本提供一定保护
AI投资回报不及预期高可能造成资产利用率不足

尤其需要关注 RPO（剩余履约义务）。

Oracle FY2027 Q1 的 RPO 达到6640亿美元，同比增长2090亿美元。

这是很大的合同储备，但不能直接当成收入，更不能直接当成利润或现金流。

我会重点观察这些指标：

  • RPO 是否持续增长。
  • RPO 是否真正转化为营收。
  • OCI 增长是否维持在高水平。
  • 资本开支是否开始下降。
  • 自由现金流能否按照管理层计划转正。
  • 净债务是否得到有效控制。
  • 流通股数量是否持续快速增加。

我的投资观点

Oracle 是一家好公司，但它目前不是一只可以只看 PE 买入的传统价值股。

我更愿意等自由现金流改善、负债受控，再提高对它的估值。

我最关心的三个问题

  • 问题1： Oracle 能不能在2029年实现300亿美元以上自由现金流？
  • 问题2： AI云业务的高速增长能不能转化为真实的股东回报？
  • 问题3： Oracle 能不能在不大量增发股票、不显著增加债务的情况下完成扩张？

如果这三个问题得到肯定答案，Oracle 的长期价值可能会被市场重新认识。

如果不能，它就可能从一家高质量软件公司变成一家高负债、重资本、回报率不确定的数据中心运营商。

我的最终态度：值得关注，分批买入比一次性重仓更合理。目前我更愿意在100–120美元区间寻找安全边际，而不是仅仅因为股价从高点下跌就认定它便宜。

十一、我建议下一步重点研究什么？

我认为 Oracle 还有一个非常重要的研究方向：它的 AI 数据中心投资究竟能产生多少真实自由现金流？

这比单纯预测未来 EPS 更重要。

可以进一步做一份 ORCL 深度投资模型，把以下内容放在一起：

  • FY2027–FY2030 营收、净利润和自由现金流预测。
  • 数据中心资本开支及折旧。
  • 债务、利息支出和股票稀释。
  • 悲观、中性、乐观三种估值。
  • 3年、5年目标年化回报率。
  • 具体买入价、仓位和退出条件。

这样才能判断 Oracle 究竟是被市场错杀，还是仍然存在价值陷阱风险。
